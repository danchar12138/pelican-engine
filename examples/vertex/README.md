# Controlled Vertex Graph Fixture

Run `npm run dev -- --project examples/vertex` from the source checkout. Tiny PNG/GLB assets are deterministic MIT test data generated by `node --import tsx tools/prepare-vertex-assets.ts`; neither example assets nor source-only generators belong in the npm package.

The sphere's authored object origin is outside the initial camera frustum. Its material graph applies a sinusoidal displacement and translation, while the engine derives bounds without disabling culling. The imported box combines a morph target and skeletal animation with the same graph through explicit `model.material` replacement.

The controls are game systems using the public SDK: `o` shifts the sphere, `c` returns its offset, `t` enables data-texture displacement, `b` changes wave amplitude, `v` displays linear distance, `n` displays normals, and `x` returns to beauty. These are example controls, not engine editor shortcuts.

Physics colliders remain explicit separate data. This fixture verifies rendering, bounds and render-ray geometry, not automatic shader-to-Rapier deformation or full CAP-17 acceptance.
