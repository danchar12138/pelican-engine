# 受管理计算纹理

本例只导入 `pelican-engine`。它在 GPU 生成 2×2 线性 rgba32float 纹理，
执行同纹理反馈和旧任务版本采样，再把采样输出交给公开材质缓冲槽。
3×2 的第二条纹理复制链同时检验非正方形坐标和大于 1 的 HDR 值。

运行：`npm run dev -- --project examples/compute-textures`。
自动化：`npm run probe:compute-textures`。输入可通过标准自动化命令触发，无需人工点击。

| 输入 | 行为 |
| --- | --- |
| u | GPU 纹理反馈并刷新呈现 |
| f | 非有限 UV 失败，消费者失败，独立任务继续 |
| c | 取消前置任务，保持旧纹理与画面 |
| w | 显式 CPU 写左上 texel，再采样刷新 |
| r | 释放终态任务，回收旧 GPU 版本 |

任务句柄不作为持久游戏状态保存；恢复时重新按名称获取纹理并派发任务。
该例用于数据/生命周期验证，任务仍读回验证镜像，不是 GPU-only 或性能基准。
