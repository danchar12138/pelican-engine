# Specular textures probe

The GLB's geometry and PNG pixels are original, generated by `tools/prepare-specular-textures-glb.ts`, and licensed under the repository MIT license. It is self-contained and uses UV0, `KHR_materials_specular` strength alpha and sRGB color RGB, and `KHR_materials_ior`. No external assets are used.

From the repository root, with dependencies installed:

```powershell
node --import tsx tools/prepare-specular-textures-glb.ts
node --import tsx tools/specular-textures-game-probe.ts --compile-only --output examples/specular-textures/.pelican/compile-probe
node --import tsx tools/specular-textures-game-probe.ts --exclusive-gpu --output examples/specular-textures/.pelican/game-probe
```

The last command launches a browser and requires an exclusive, non-fallback WebGPU adapter. It saves screenshots and samples for raster, path, and hybrid; compile-only never reports a rendering pass. Black base color, zero ambient, and a directional light isolate specular reflection. The first four bands are gray, zero-alpha red, full-alpha red, and green. Strength RGB is always zero and color alpha is always zero, so using the wrong channels fails. The symmetric SDK `#808080` plane checks sRGB decoding. A successful small-scene hardware run is recorded in `evidence/m3/development/specular-textures-1793899600/`; it is not milestone acceptance or broad material conformance.
