# 刚体角运动

此项目只导入 `pelican-engine`。两个质量和尺寸相同的刚体分别接收中心与
偏心冲量，便于检查线速度、角速度和可见旋转；静态刚体用于验证类型诊断。

源码渠道运行 `npm run dev -- --project examples/angular-physics`；独占 GPU
的自动验证是 `npm run probe:angular-physics`。

| 输入 | 动作 |
| --- | --- |
| i | 对两个刚体施加相同世界空间冲量，一个作用于质心，一个作用于偏移点 |
| t | 对偏心刚体施加世界空间力矩冲量 |
| v | 设置中心刚体世界空间角速度为每秒 1 弧度 |
| f | 尝试对固定刚体施加力矩，记录类型错误码 |

这些接口使用 Rapier 实际刚体结果并参与现有快照／回放，不暴露底层对象；
本例不是完整 M4 的关节、车辆或形变／流体模拟验收。
