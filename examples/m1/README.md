# M1 基础运行时示例

只使用公开 SDK。输入通过 `input.key` 事件进入固定模拟步；系统声明组件读写权限和阶段。旋转、状态计数、可控随机数、延迟事件均由正式运行时管理。

在引擎根目录运行 `npm run dev`。外部游戏可通过 `pelican.ps1 create --project <新目录>` 复制此模板。运行时当前固定 60 Hz；普通开发页和生产版自动运行。外部工具的 `?automation=1` 测试页显式暂停，可以直接单步或恢复运行，无需手工激活窗口。

`Progress` 用于验证快照、随机与事件恢复；它不是 UI 或完整任务系统。渲染器仍保留明确标记的 M0 光追原型，生产光追能力按后续里程碑交付。
