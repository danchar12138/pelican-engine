# Reproduce this candidate5 game validation

Run in the new `candidate5` flow directory with `powershell.exe`, setting `$OutputEncoding=[Text.UTF8Encoding]::new($false)`. Scripts resolve the local engine at `threecat` and store evidence in `report`; no Git is needed.

1. On a fresh extraction, `node report/run.cjs 01-engine-baseline -- node ../report/audit.cjs before`. A baseline intentionally cannot be overwritten. `node report/audit.cjs after` verifies the existing baseline at the end.
2. Use `threecat/threecat.ps1 setup --install-browser` and `setup --offline` through PowerShell. The locked local browser is reused; do not create an empty browser cache.
3. Copy the existing authored game source/assets into `threecat/games/core-relay`, or create that directory from the template on a fresh extraction and overlay `report/game-source/`. The project `engine.path` is `../..`. The final `game.ts` declares `exit-gate` as **kinematic**.
4. `node report/run.cjs check -- powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./threecat.ps1 check --project ./games/core-relay`.
5. The intentional negative and repair are `intentional-negative.patch` and `asset-fix.patch`, applied from the candidate5 flow root. Check must exit 1 with TC_ASSET_MISSING, then 0 after repair. Actual recorded commands 09 and 10 contain the diagnostics.
6. `node report/kinematic-repro.cjs` creates the same minimal player/floor/gate games under engine games, runs the original contact/retreat sequence, and now asserts the kinematic case **must move away**. It also retains a fixed control case. It closes both repro servers and browsers.
7. Start the dev server at port 4319 with `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./threecat.ps1 dev --project ./games/core-relay --port 4319` from the engine directory. For background launch use `Start-Process -WindowStyle Hidden` and record the PID/stdout/stderr. Then `node report/gameplay-test.cjs` runs the full original game and cold restore through the documented external `window.__threecat.command` protocol. Game source never calls the test bridge or imports internals.
8. Build via the engine CLI, copy `threecat/games/core-relay/dist` to `deployment/relay`, then `node report/managed-static.cjs`. It starts an independent static server, runs production keyboard/save/cold-restore assertions and shuts down its server/browser processes. It verifies the deployed IR gate is kinematic.
9. `node report/archive-evidence.cjs` compares every deployed file hash, copies selected small source/build evidence and verifies exact cold gameplay-record equality. `node report/assess-results.cjs` writes the physical-body extraction and actual candidate4/candidate5 before/after comparison.
10. `powershell.exe -NoProfile -ExecutionPolicy Bypass -File report/cleanup.ps1` closes the recorded dev server and verifies owned ports/browser profiles are no longer active. `node report/finalize-report.cjs` produces `flow.json`; `node report/validate-report.cjs` validates its source identity, artifact references and underlying assertions without rerunning gameplay.

Original candidate4 evidence remains outside this directory at `../report/`; this report explicitly records its mainline rejection and the engine-side resolution. Large complete snapshots and compressed protocol traces remain local; small formal artifacts are listed in `flow.json`.
