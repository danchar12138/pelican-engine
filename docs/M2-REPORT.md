# M2 游戏切片与资产管线报告

版本 `0.2.0-m2.0`。695 项测试、15 项门禁及两条冻结 ZIP 独立 AI 使用流程全部通过。以 `evidence/m2/acceptance.json` 的源码指纹、逐项状态和对应远端 Release 为准，不从文档中的实现列表推断门禁通过。最终源码指纹为 `857f76bd1d85de6d0e05b8ce5b08a2009b7d74b5692f38dbda39ed76ca5d44a2`。

## 已实现链路

第三人称示例只通过公开 SDK 编写，包含角色移动/跳跃、跟随相机避障、真实胶囊与刚体、骨骼片段切换、巡逻障碍造成伤害、三物品收集、任务 UI、音效、保存与通关场景切换。真实 Chromium/WebGPU 验证已从初始场景走到通关，并在通关后及刷新页面后读取旧存档。损坏存档保留当前状态、重试可恢复；输入录制重放、跳跃落地和纹理场景拒绝不支持的 path 模式都有断言。

GLB/PBR、PNG/JPEG 与 WAV 处理从真实字节生成元数据，检查资源边界、动画和骨骼。Fox 和 WaterBottle 的来源、哈希、许可和归属随源码、编译 notices 及 dist 保留。无损 GLB 优化保留原文件，实际比较三角形顶点流；静态构建保留原始文件并附带可选 Brotli/Gzip 传输副本，协商和归档内容均有校验。

运行时插件将输入、物理、动画、UI、音频、相机和平台请求接入固定调度。存档/切场景在完整 tick 后执行，候选内容准备失败不替换当前场景。模型快照能恢复淡入进度、已删除实例与冷启动集合；公开预制体的默认数据、内容身份、运行时生成与快照由 World/Host 统一持有。

独立 AI 使用验收曾发现角色接触 kinematic 门后无法退回。主线使用相同三实体场景复现，定位为 Rapier KCC 在零距离地面/运动学障碍接触中耗尽碰撞迭代；已增加有条件的原生胶囊 sweep/slide 恢复，并保留正常重力、其他实体阻挡与常规控制器行为。`examples/physics-risk` 与 `kinematic-regression.json` 验证接触、退回、开门、快照和重放；物理测试还覆盖支撑移除、平台边缘、薄墙和墙角。旧候选报告与游戏侧规避过程保留，但不作为最终修复通过依据。

## 证据与测量

`tools/verify-m2.ts` 实际运行环境、类型、全量测试、编译、资产、物理、运行时、控制协议、无人值守启动、真实渲染、部署、独立 AI 和源码冻结共 15 项门禁。测试失败、尝试记录和缺失证据保留，不手动改通过状态。

`render.json/journey.json` 包含真实后端、适配器、每步玩法状态和恢复结果；图像序列包含拾取、全收集和通关。原生 1080p 的原始 RAF、CPU 提交及模拟采样见 `performance.json`；GPU timestamp 未提供时明确为 null，不把 RAF 间隔当作 GPU 执行时长。该切片和当前显卡的测量不代表所有主流电脑负载或完整画质验收。

`deploy.json` 使用独立静态服务器与子路径，真实键盘输入拾取/存档，并在页面刷新后恢复；生产产物没有开发控制接口。`unattended.json` 在不点击、不按键且不激活游戏页时检查自动推进，以及禁用 RAF 的测试页就绪、单步和截图，防止启动再次依赖人工激活窗口。

M0-08 的 UI 风险专项接入 `examples/ui-risk` 和必需的 `ui-prototype` 门禁，记录 Chromium 原生文本组合/提交、选择区间、输入焦点与玩法键隔离、虚拟标准手柄焦点序列，以及真实场景矩阵投影、网格遮挡、元素命中和世界按钮点击。手柄样本为虚拟输入，未声称实物手柄或 OS 输入法候选窗已验收；完整布局/设备/字体/可访问性仍属于 M6。

独立 AI 使用报告必须绑定冻结 ZIP 和源码指纹，覆盖无 Git 的目录内和外部项目、实际新增玩法、预期错误与修复、构建和部署；缺失报告时整体验收失败。

## 保留限制

- M2 是阶段性游戏切片，完整首发范围没有缩减；M3–M8 仍须完成。
- 带纹理 GLB 当前只通过 raster 忠实显示，完整材质 hybrid/path、降噪及动态路径追踪属于 M3。
- 素材管线目前有明确格式/扩展边界，不支持的压缩资源不会静默近似。无损预处理和 HTTP 压缩不等于纹理转码、网格量化或完整 LOD 体系。
- 物理快照通过操作历史重建校验，存在操作上限、增长的存储及恢复成本；长期固定大小 checkpoint 仍待优化。
- 基础 text/bar/button、buffer audio 和角色/刚体不等于 M4/M6 的完整模拟、UI、音频和多类型游戏矩阵。
- 浏览器模块缓存、GPU 内存释放及长时间资源稳定性不能仅凭所有权计数宣称解决；M7 须继续实测与优化。
- 代码变更当前触发明确冷重载，不承诺任意状态热替换或跨版本存档迁移。

多代理实现使用独立 worktree、同一基线与互不重叠的写入范围。主线按基线哈希审查合入后统一验收；子任务的通过结果不替代里程碑门禁。发布仍由主线在同一交付节点完成中文 Conventional Commit、推送、CI、标签和 Release。
