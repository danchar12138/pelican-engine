# threecat M2：游戏切片与真实资产管线

版本 `0.2.0-m2.0`，定位为可玩游戏切片 prerelease。695 项测试、全部 15 项门禁和两条冻结 ZIP 独立 AI 流程均已通过，正式证据见 `evidence/m2/acceptance.json`。

本阶段交付公开 SDK 编写的 Fox Journey、GLB/PBR/骨骼动画、角色和刚体、运行时预制体、跟随相机、基础输入/UI/音频，以及跨场景和冷启动存档。补齐了真实素材检查、来源/归属 notices、无损 GLB 优化、静态 HTTP 压缩和当前页自动化控制。普通启动无需点击或回车，后台遮挡和无 RAF 回归持续验收。

Windows 下读取根 `AGENTS.md` 和 `docs/M2-USAGE.md`。引擎可由 Git、ZIP 或本地目录使用，在引擎内或外部游戏目录开发；构建输出 `dist/`，部署到普通 Web 服务器，包括子路径。游戏源码仅使用公开 API，不调用 Three.js、DOM、原生 GPU 或 Rapier 内部对象。

完整验收步骤、原始测量、图像序列和已知限制见随包 `evidence/m2/` 与 `docs/M2-REPORT.md`。M2 不是完整首发引擎：纹理场景目前使用 raster，完整材质光追/路径追踪在 M3；交互模拟、大世界、完整 2D/UI/音频、迁移和首发验收继续按 M4–M8 推进。物理历史快照的长会话成本和操作上限明确保留，不用小场景吞吐冒充所有游戏性能。
