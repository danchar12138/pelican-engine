# 1.1.0 — AI-first stabilization

Fixes runtime defects found in the November 8 review: native lifecycle actions,
scratch-backed inertia samples, fixed session history exhaustion, duplicate UI
after button-driven load, focus release and viewport/DPR handling. Native v4
checkpoints bound replay history and retain legacy v3 reconstruction. Shared model
material animation now preserves authored baselines and live poses across mixer
teardown and replacement restore.

The external-AI interface adds pointer/pen/touch state, deterministic pointer
injection, preflighted command batches, progressive quality rendering, searchable
API signatures, implementation capability discovery, JSON recipe source and
recipe templates. Content compilation supports bounded pure local helpers and
collection transforms. Components support bounded structured JSON. Approved
runtime-only npm libraries are bundled and fingerprinted without granting access
to renderer/GPU/native physics internals.

Production follows native viewport/DPR and hides the diagnostic HUD. Explicit
capture width/height pin automation pixel size. No automatic quality reduction is
introduced. CI runs type, regression and distribution checks before OIDC publish.

Validation: 1784 main-suite passes, zero failures, all five separately enabled
GPU/model-browser cases passed, 24 installed-game workflows passed, 53 examples
compiled, 16 distribution contracts and offline smoke passed. Source identity,
preserved failures and limitations are recorded in the [evidence summary](../../evidence/ai-first/1.1.0-2026-11-08/summary.json).
A same-scene emissive-only comparison demonstrates indirect
transport versus stock Three.js raster. It does not establish a universal quality
ceiling or independently measured AI task-time superiority. Advanced combined
animation/world/solver coverage and broad hardware acceptance remain separate.

This file is source release notes, not evidence that npm or GitHub publication
has happened. Check the actual registry and publishing workflow result.
