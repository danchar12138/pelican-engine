# Pelican Engine 0.3.0-m3.0

状态：M3 开发预发布，compile-only / unverified，不是完整 M3 验收或 1.0 发布。

本版本包含 Pelican Engine 单 npm 包、`pelican` CLI、受控渲染及计算接口、WebGPU 优先与 WebGL2 回退实现，以及动态混合光追和路径追踪的研发候选。M4–M6 的少量既有实验代码随主线存在，不代表对应里程碑完成。

依据 D50，本次仅执行 TypeScript 编译、M3 示例构建与 npm 分发构建打包，不执行测试、浏览器、GPU、性能、smoke 或正式验收。编译及构建成功不证明运行、画质、性能、设备恢复或跨渠道行为正确。WebGL2、WebGPU、真实动态光追和路径追踪的当前行为均未验证；不声称硬件光追单元支持。

完整材质、动态场景、时域质量、资源生命周期、兼容性、独立游戏开发及正式验收仍有缺口；详细开发状态见 `docs/tasks/M3.md` 和 `docs/tasks/M3-RELEASE-QUEUE.md`。历史开发报告仅适用于各自记录的旧源码，不能证明本预发布通过；本次发布不重新执行或篡改这些记录。

旧开发证据和工作树中的未合并成果保留在本机，后续需按来源逐项收敛。源码、静态构建和 npm 包的发布状态以实际交付结果为准，不因本文件存在而推断发布成功。
