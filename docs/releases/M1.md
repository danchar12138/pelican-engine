# threecat M1：核心契约与编译运行基础

版本 `0.1.0-m1.0`，属于基础运行时预发布，不是完整首发引擎。

## 主要交付

- 正式编译器、强类型 SDK、系统依赖/权限和项目版本锁定检查。
- SoA 实体组件存储、代际句柄、原子结构命令、固定步调度和受控随机。
- 事件、完整运行时快照、输入录制与重放，以及明确的故障与恢复语义。
- 资源共享、作用域、异步取消、迟到结果清理和失败恢复。
- 浏览器权威状态整合、内容候选事务、可视实体恢复和 WebGPU 生命周期处理。
- 版本化命令行检查、分页、输入、单步、快照、录放、取消与当前帧截图。
- SDK 派生的 API 索引和 Schema，独立 dist 静态子路径部署。

## 无人值守启动修复

普通开发页和生产游戏初始化后自动运行；只有显式自动化测试会话暂停，并显示清晰状态。就绪检查不依赖 RAF、焦点、点击或回车，Node 和 GPU 等待均有截止时间。

真实 GPU 回归在不发送输入、不激活游戏页的条件下验证了：被覆盖页面仍自动推进；完全禁用 RAF 的自动化页仍能就绪、单步到 tick 3 并截图。此项已经成为发布必需门禁，不是仅修改状态文案。

## 使用方式

读取根目录 `AGENTS.md` 与 `docs/M1-USAGE.md`。Windows 下：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\threecat.ps1 setup --install-browser
powershell -NoProfile -ExecutionPolicy Bypass -File .\threecat.ps1 dev
```

可在仓库内或外部目录创建游戏，无需 Git。构建产物为 `dist/`，发布到 Web 服务器运行；开发控制不会进入默认生产产物。

## 验收与限制

正式结果以随包的 `evidence/m1/acceptance.json` 为准，包含类型、CPU 测试、编译、运行时、资源、调度、协议、无人值守启动、真实 GPU、部署及冻结 ZIP 独立 AI 使用证据。失败与修复记录保留。

M1 仍使用有限的静态声明子集和整项目缓存，代码变化采用明确冷重载，不承诺任意状态热替换。路径追踪保留 M0 原型边界，生产级图形、完整物理、资产、UI、音频和大世界能力继续按 M2–M8 推进。
