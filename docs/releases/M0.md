# threecat M0：首个里程碑风险原型

这是 `threecat` 的首个开源里程碑预发布，版本 `0.0.1-m0.0`。**M0 已完成技术验证，不是完整游戏引擎首发版。**

## 本次交付

- TypeScript 声明、组件、预制体和场景编译，公开 SDK 子集、图形 IR、普通玩法 JS、内容哈希缓存及可定位诊断。
- 真实 WebGPU-only 光栅、光追图像合成和动态软件 BVH 路径追踪；验证骨骼、Morph、模拟形变、几何增删与相机运动。
- 绳索、布料、软体、流体的真实小规模 CPU 双向接触，以及 Rapier 2D/3D WASM 候选验证。
- 有限世界分块、异步流送、事务修改、碰撞/导航数据同步、持久化和快照恢复。
- Windows 自动准备、仓库内及外部目录开发、结构化命令、真实截图和可独立部署的 `dist/`。

## 验收结果

- 严格 TypeScript 检查、**165 项测试**和全部 **10 个 M0 检查**通过。
- NVIDIA RTX 5070 Ti Laptop 的有界面真实 WebGPU 验证通过，不使用软件适配器冒充硬件。
- 无研发历史上下文的外部 AI 从冻结 ZIP 完成两条流程：仓库内游戏和外部中文路径游戏，分别通过 **21 项、27 项浏览器检查**。
- 包含故意报错、源码定位、修复、玩法变更、键盘操作、冷启动、快照恢复、真实截图和独立静态部署。
- 失败、测试脚本错误、修正及复测记录均保留。M0 验收绑定可执行源码指纹，不能用过时结果替代当前版本。

## 下载与运行

- `*-source.zip`：引擎源码、锁文件、指引、测试与验收证据；无需 Git。
- `*-dist.zip`：解压后将内容发布到 Web 服务器，即可运行 M0 演示。
- `*-evidence.json`、`*-manifest.json`、`SHA256SUMS`：证据索引、文件清单和校验值。

源码目录的外部 AI 入口为 `AGENTS.md`，实际操作见 `docs/M0-USAGE.md`。Windows 下运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\threecat.ps1 setup --install-browser
powershell -NoProfile -ExecutionPolicy Bypass -File .\threecat.ps1 dev
```

开发环境仅支持 Windows；玩家端不设浏览器或操作系统白名单，按实际 WebGPU 能力启动，不回退 WebGL。

## 重要限制

路径追踪是软件三角 BVH 与简化积分，没有专用硬件 RT 接入或生产降噪。混合模式仍是图像合成试验。原生 1080p 小场景的五跳路径追踪串行墙钟约 28 ms，**尚未达到完整高质量游戏的 1080p60 目标**，该数字也不是持续呈现帧率。

高级模拟是小负载参考，尚无完整通用多模块耦合；完整 ECS、资产、UI、音频、动画、大型世界与玩法模块继续按 M1–M8 实现。不会把原型通过宣传为完整首发能力完成。
