# M1：公开契约与编译运行基础

状态：M1 实现与验收通过，进入统一发布节点。用户已授权连续自动推进 M1–M8；发布完成后接续 M2，不将未完成能力提前标为通过。

## 任务范围

- M1-01：将 M0 编译器迁入正式包，保留实验入口兼容，补齐系统元数据、版本检查与契约索引。
- M1-02：数据导向组件存储、代际实体句柄、结构命令、父子关系、事务式快照恢复。
- M1-03：固定步长、随机源、系统依赖和读写权限、事件、录放与调度状态。
- M1-04：类型化资源句柄、共享/作用域、异步取消、过期结果释放与失败恢复。
- M1-05：以运行时为浏览器权威状态，连接编译内容、输入、诊断、截图及静态构建。
- M1-06：版本化工具协议、运行态检查、API 单一事实来源和真实自动化验收。
- M1-07：干净 ZIP/外部目录独立 AI 任务、Windows CI 与 M1 Release。

## 交付规则

先固定核心契约再并行实现，写入边界不得交叉。主线集成后执行单元、契约、浏览器、失败分支和干净环境验证。只有全部 M1 门禁通过才更新版本、在同一节点提交、推送和发布；代码修改后不得复用过时验收证据。

M0 原始证据保留为历史记录；当前版本的验收写入 `evidence/m1/`。M1 不是 M2 游戏切片或 M3 生产光追能力的提前交付。
