## 明确语义

- MaterialInput.vertex 提供 position/normal 两个可选 vec3 图，至少一个。输入为 positionLocal、normalLocal、vertexIndex、instanceIndex、uv/uv1、time 和参数，支持已声明纹理的 base-LOD 采样，不接受任意 shader/Three/GPU 对象。normalLocal 为归一化输入；输出法线为零时保留它。
- 位置域是内置 morph、骨骼、实例变换之后、对象 matrixWorld 之前。这与锁定 Three NodeMaterial.positionNode 的实际执行位置一致。两个图读取同一输入快照，不因先赋值法线而改变位置图的输入。
- 光栅使用真正 GPU 顶点节点；CPU 表面提取按相同图做 f32 逐节点求值，用于路径/混合 BVH、渲染射线查询和动态包围体。不是用未变形网格冒充变形光追，也不把 CPU 镜像称为 GPU BVH refit。
- 游戏 Transform 和显式物理 collider 与材质顶点图是不同状态，本轮不宣称自动把 shader 变形回写到 Rapier 碰撞体。物理变形/耦合仍由 M4 验收。未提供法线图时保持原着色法线，任意变形不会自动推导正确微分或切线。
- model.material 提供显式整模覆盖来使用游戏材质；模型库只借用，不拥有/销毁它。省略时保留资产材质与原有动画/纹理行为，当前不支持源槽级的选择性覆盖。
- 正常渲染保留剔除，依据同一 deformed CPU 几何维护对象级包围体，不通过关闭剔除掩盖过期 bounds。仅含顶点图的对象进入额外 CPU 镜像；静态/未变输入复用缓存。
- 缓存签名必须包含相关图、时间、参数、纹理版本及本来的几何/morph/skin/instance 状态。成功提取后才提交缓存；非有限/退化几何明确诊断，保留旧 BVH 的原子性。

## 附带的确定缺陷

内部后处理 MRT 名称 depth 会被 NodeMaterial.setupDepth 解释为硬件片元深度覆盖，不能用于世界距离输出。内部附件改为不保留的 linearDepth，公开 scene.depth 不变。补近/远遮挡小场景，不扩大到整套后处理质量矩阵。
