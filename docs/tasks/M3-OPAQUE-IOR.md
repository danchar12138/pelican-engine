# M3 不透射物理材质折射率

本任务落实已有 `MaterialInput.ior`、CAP-13 至 CAP-16 的材质一致性，不新增首发范围，也不代表 M3 已验收。

状态：开发增量实现及受影响验证通过，尚未发布。证据 `evidence/m3/development/opaque-ior-1793892642802/summary.json`，源码指纹 `fd7b733cac44e938d12cdd73080854bcc965db296ca16876e91df050e8d6df45`。

## 契约

- 不透射的非金属物理材质允许使用有限正数 IOR；介质法线入射反射率为 `((ior - 1) / (ior + 1))²`，而不是对所有值固定为 0.04。默认 IOR 1.5 保持既有默认反射行为。
- 光栅、hybrid 与 path 使用相同材质 IOR。对于混合金属度，介质 F0 与金属 baseColor F0 按既有金属度混合；表面传输、体积吸收与材质不透明度保持各自语义，不将不透明反射冒充透射。
- path/hybrid 的直接照明、采样分布、PDF 和 MIS 使用一致的 F0；不允许只改显示结果而不改采样权重。既有传输介质路径与默认 1.5 的结果保持兼容。
- 显式负数、零或非有限 IOR 明确诊断。物理扩展中未实现的清漆、各向异性等仍明确拒绝，不得静默降级。

## 执行与验证

独立 worktree 负责物理材质的 CPU 参考、渲染路径、编译/捕获接入和定向测试；主线负责公开游戏与独占 GPU 的三模式端到端集成、集中类型检查和文档。数值、图像因果和失败诊断分别记录，不将单个场景宣称完整材质矩阵。

按 D49 只做受影响测试、一次集中类型检查和小型真实 GPU 链路；不重复全仓/1080p/npm 安装矩阵。仍需 M3 的完整高质量、故障、独立 AI 与分发正式门禁。

## 验证结果

- 受影响测试共 177 项，其中 175 项通过、2 项 GPU opt-in 默认跳过；随后分别独占 GPU 启用 BSDF 与 dielectric 两组硬件回归，11/11 与 10/10 通过、零跳过。这些是重叠测试，不相加为独立覆盖。统一类型检查通过。
- 实际 NVIDIA 非回退 WebGPU 数值探针对 IOR 1.1／1.5／2.0 验证 BSDF 求值、PDF、采样方向及权重，对比 CPU 参考；默认 BSDF 和原有 dielectric 各完成 773 个硬件数值包。
- 320×240 的公开游戏在 raster/path/hybrid 中比较左右对称视角的 IOR 1.1 与 2.0 黑色平面：三模式高 IOR 均有更强的实际高光。屏幕中间 IOR 1.5 因视角不同只验证有反射，不据此声称三者亮度排序或逐像素光栅／PT 一致。
- 第一次光栅截图验证曾错误假设三个不同视角的平面必须单调递增；原始失败保留于 `evidence/m3/development/opaque-ior-1793892603383/`。改为比较对称视角后通过，没有改变渲染质量或阈值以掩盖结果。

本增量不包含彩色高光、清漆、薄膜、各向异性等其余 PhysicalMaterial 扩展，也未覆盖完整高质量材质矩阵、当前 npm 安装或 M3 正式验收。首次物理步前删除缺陷仍独立开放。
