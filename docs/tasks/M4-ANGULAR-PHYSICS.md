M4 与 M3 可在共享时间/实体/快照契约确定后并行。本增量不是 M4 完整验收。

状态：角运动增量实现与局部验证通过，未发布。证据 `evidence/m4/development/angular-1793887575482/summary.json`，源码指纹 `1aa2ed07d85afbcf6a34b060b462d20e48dbca4824c35ef39b832155d3b5c7da`。M3 仍是当前正式里程碑，不能用本增量跳过 M3 或 M4 完整门禁。

- 游戏侧唯一接口 `ctx.physics.angularVelocity/setAngularVelocity/torqueImpulse/impulseAtPoint`。角速度为世界坐标弧度/秒，冲量和作用点都使用世界坐标；力矩冲量单位是角动量。
- 使用现有 Rapier 刚体，不公开 Rapier 句柄。查询需要有效实体；设置与冲量只接受 dynamic 刚体。字符、固定和运动学刚体明确 `TC_PHYSICS_BODY_TYPE`，失效实体、非有限向量及参数给现有确定诊断。
- 写操作进入现有验证后记录的 history，使快照预检、原生世界一致性校验、重放、恢复、代际失效、销毁与碰撞同步保留旧语义。旧快照和已有调用行为不变，坏输入不部分改变刚体或历史。
- 独立 worktree 只改 `packages/physics/index.ts` 与专属测试；主线负责 SDK、AI 文档、样例和真实浏览器验收。受影响测试、集中类型检查和一条小型真实硬件场景；正式 M4 验收仍需关节、车辆、布料、绳索、软体、流体等。

## 实际结果

- 190 项受影响测试通过，零跳过；类型检查通过。Rapier CPU 数值测试验证质心/偏心冲量、角速度、力矩冲量、错误类型与数值、快照篡改、恢复、实体生命周期和旧物理契约。
- 一条 320×240 NVIDIA 非回退 WebGPU 公开游戏链路：质量 2、边长 1 的刚体被相同冲量作用，质心角速度为 0，偏心 0.4 的角速度约 -1.2000006 rad/s；20 tick 后偏心物体旋转约 -0.42 rad，中心物体未旋转。直接设角速度约 1 rad/s，0.2 力矩冲量使偏心物体角速度增加约 0.6 rad/s；固定体错误码 `TC_PHYSICS_BODY_TYPE`。
- 存档恢复、回放、24 三角形路径追踪及最终零资源通过。截图和真实适配器记录位于证据目录；不把小型场景称为完整物理或性能验收。

## 开放生命周期缺陷

现有 Rapier 0.21 初始化先以零 dt 执行 step。若在首次正常物理步之前移除动态或运动学刚体，且仍有其他动态／运动学刚体，后续正常 `world.step` 可触发 `RuntimeError: unreachable`。该路径在本次角运动改动前已存在；独立原生复现 `tests/physics-initial-remove-regression.ts` 不匹配日常 `*.test.ts`，失败日志归档在本增量证据中。

不能用“先运行一帧”当作修复或把缺陷标记已验收。后续需设计兼容即时查询与原生快照重放的初始化／拓扑同步方案，并建立插件及真实游戏回归后再关闭；真实游戏复现及已排除方案见 [首步前删除缺陷](M4-FIRST-REMOVAL.md)。关节、车辆、布料、绳索、软体与流体等仍未由本增量覆盖。
