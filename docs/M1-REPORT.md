# M1 基础运行时报告

版本：`0.1.0-m1.0`。状态：472 项测试、12 项门禁及两条冻结 ZIP 独立 AI 流程通过。正式结果见 `evidence/m1/acceptance.json`。独立流程分别包含 33/34 条成功命令、各 2 条故意负例，未修改引擎、无人技术介入。

## 已实现

- 正式编译器包、系统依赖/权限元数据、项目引擎版本与路径身份检查、跨盘 source map 和整项目内容哈希缓存。
- 真实 SoA 组件列、扩容、稳定查询、代际句柄、父子关系和原子结构命令；快照恢复使旧句柄失效。
- 六阶段固定步调度、读写权限、可控随机、事件、快照和输入录放；部分 tick 故障明确暂停，不伪报成功。
- 资源共享、引用与作用域、独立取消、迟到结果释放、失败重试和身份快照。
- 浏览器以 RuntimeHost 为权威状态，显示对象仅为派生；加载候选事务失败保留旧状态，删除/恢复会重建可视对象。
- 结构化命令行的查询、输入、单步、快照、恢复、录放、分页诊断和当前会话截图；超时/取消明确报告状态重置。
- 公开 SDK 派生 API 索引和组件 Schema；生产 dist 剔除控制接口并通过普通静态服务器子路径运行。

## 证据

CPU 测试包括真实 World/Host/资源/编译集成，不把合成控制页或 Release fixture 当作 GPU 证据。最终数量以当前验收输出为准。

真实 headed WebGPU 验证涵盖运行时输入和固定步、状态/随机/事件恢复、trace 重放、图形计算读回、动态路径追踪、资源重复加载和加载失败保留旧状态。控制桥截图来自其持有的当前页，不是另开场景冒充当前状态。

性能记录只报告指定机器和负载，10,000 实体的创建/查询数据不代表所有游戏吞吐。结构命令原子实现目前复制候选状态，后续需按热点优化。资源计数是所有权，不等于 OS/GPU 无泄漏的完整证明。

## 限制与下一阶段

用户报告的 `Waiting GPU / ready` 停滞已修复：普通开发页初始化后自动运行；测试模式显式暂停并清晰显示状态。外部工具改用非 RAF 的就绪检测与 Node 截止时间，GPU 等待有界。真实硬件回归在不点击、不按键、不激活游戏页的条件下，验证了被覆盖页面自动推进，以及完全禁用 RAF 时仍能就绪、单步和截图。详见 `evidence/m1/unattended.json`。

M1 不是完整游戏引擎首发。静态声明仍是受限 TypeScript 子集；缓存为整项目复用；开发变更采用明确冷重载，不是任意状态热替换。原生 JS module cache 无法卸载。

生产光追/BSDF/降噪、纹理与模型管线、角色/物理/动画、完整 UI/音频、大型动态世界和玩法模块仍在后续里程碑范围。M2 将优先实现只用公开 API 的完整游戏切片、真实资产接入和高质量光栅基础，不用私人测试舞台代替用户游戏。

版本发布遵循：验收通过 → 中文 Conventional Commit → 推送与远程 CI → 相同提交标签和 Release → 核对附件摘要。未通过独立验收时不得发布。
