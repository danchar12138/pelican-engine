## Runtime distribution

The 3D engine adapter now uses a locally modified build of Rapier commit b716d375efc0201003f0cd9ef7168eee0b62c177 (JS bindings 0.21.0). The persistent-island bootstrap change, build provenance and original Apache-2.0 license are shipped under packages/physics/vendor/rapier3d (lib/physics/vendor/rapier3d in npm). This is a Pelican-maintained build, not an official upstream npm release. The stock 3D npm package remains a type/build dependency; the 2D runtime is unchanged. The historical inventory below describes upstream dependency packages, not acceptance of the modified native runtime.

The browser bundle uses Three.js 0.187.0 (MIT, three.js authors), @dimforge/rapier3d-compat and @dimforge/rapier2d-compat 0.21.0 (Apache-2.0, Dimforge contributors). Their complete distributed licenses are copied to THREE-LICENSE.txt, RAPIER-LICENSE.txt and RAPIER2D-LICENSE.txt in dist. The 2D adapter is loaded for scenes that opt into 2D physics. The browser PNG decoder fast-png 8.0.0, fflate 0.8.3, iobuffer 6.0.1 and navigation library ngraph.path 1.6.1 are MIT licensed; their license texts also accompany dist. M0 geometry and simulation probes are generated by pelican.

The M2 Fox and WaterBottle assets are fixed to KhronosGroup/glTF-Sample-Assets commit 8f492390ddc7a2ae221a1369ef560589cf8c70fb. Fox model: PixelMannen (2014), CC0-1.0; rigging and animation: tomkranis (2014), CC-BY-4.0; glTF conversion: AsoboStudio and scurest (2017), CC-BY-4.0. WaterBottle: Microsoft (2017), CC0-1.0. Original metadata and file hashes are retained in examples/m2/assets/. Game definitions carry source/license/attribution into generated/asset-notices.json and dist/THIRDPARTY-NOTICES.txt. The chime is procedural PCM generated by pelican under MIT. Asset checks do not certify the rights of a user-supplied asset; undeclared licenses remain explicit warnings.
