# 当前研发状态

## 版本与发布

- 当前版本为 `0.3.22`，包、锁文件、引擎、SDK、编译器和示例中的版本保持一致。下一项功能完成后统一递增并推送；相同版本不能重复发布。
- 推送主线会通过 GitHub Actions 和 npm 可信发布更新 `latest`；GitHub Release 用于记录里程碑。历史版本和旧标签保持原样，不代表当前源码通过。
- 当前按用户要求仅允许编译和构建，不运行测试、浏览器、GPU、性能或其他验证。普通版本号不意味着运行行为、硬件或完整引擎已验收。

## 已有基础与缺口

- TypeScript SDK、编译器、游戏运行时、渲染器、资源管线和命令行已有实现；游戏开发使用 `pelican-engine` 公开接口。
- 动态光追、路径追踪、受控图形计算和 WebGL2 回退已有研发实现，但当前源码的完整画质、性能、兼容性和资源生命周期未验证，不能称为完整首发。
- 刚体首步前删除存在已知缺陷；历史候选存在旧快照兼容及危险历史回放风险，不得通过修改夹具或在主进程回放危险历史掩盖。有关背景与原始证据保留在历史任务文档中。
- 正交网格导航新增批量障碍更新接口；它只处理单个网格的阻挡状态，不等于世界流送、实体变换或物理联动。该增量尚未进行运行行为验证。
- CPU 粒子绳索已接入 `ctx.ropes` 和 Host 快照，支持手动或自动固定步进。显式绑定的动态非触发球体可在物理阶段后被采样，并接收绳索投影产生的反冲量；其他采样球体/平面仍为单向。可选分段圆柱实例随粒子位置更新；它不是连续变形绳索网格。新绳索默认对绳段内部与球体的离散重叠求解，旧粒子型快照保留原模式；新增非相邻绳段间离散自接触和扫掠式宽相，可关闭；尚无完整双向求解、跨绳索碰撞、连续碰撞或撕裂。渲染、碰撞、性能、运行行为和快照兼容均未验证。
- 动态球体绑定的接触响应已纳入刚体接触点速度、有效逆质量和转动惯量；绳索阶段使用虚拟状态、按绳索顺序求解并延迟提交冲量。真实刚体位移在下一物理步更新，仍无全局耦合子步、摩擦、恢复系数或连续碰撞，不代表完整双向物理。稳定性、守恒、运行和快照兼容尚未验证。
- 三角布料新增 CPU 距离约束、近似弯曲、锚点、受力、采样球体/平面粒子碰撞、非相邻粒子自碰撞、Host 快照及动态网格入口；不包含面/边碰撞、刚体反作用、撕裂或连续碰撞。渲染、运行、稳定性、性能和快照兼容均未验证，不代表完整布料能力。
- 布料、绳索、软体、流体、连续世界、导航、动画、音频和其他首发能力仍需按各自依赖完成，不能把独立候选或局部实现写成整项完成。


- Historical cloth snapshots without `selfCollisions` restore in the legacy particle-only mode; invalid or duplicate self-contact state is rejected atomically. This migration fix is unverified.

- Cloth automatic stepping can bind live dynamic non-trigger spheres and sample their center and radius after physics as one-way moving obstacles; no reaction impulse is applied. This interface is unverified.

## 单线接续

只在 `main` 的主工作树串行开发。历史独有候选和失败记录在本机 `.pelican/consolidated-worktrees/`、`.pelican/worktree-snapshots/` 或原证据目录中；它们不是活动工作树，未审查前不能删除或声称已合入。其他环境不一定有这些本机目录。

每次工作只积累一个功能、修复或下一版本的相关变更；完成后及时提交并推送，不等待里程碑。推送前同步递增标准版本，以便 npm 使用同一版本发布。历史本机开发报告可由本机 Git 排除配置隐藏，不删除原文件；正式证据和未来新报告不能因此被默认为已提交。

下一步优先分析物理生命周期与旧状态兼容的实现边界，再按依赖逐步集成可用功能。保留真实失败、局限和历史来源；不在禁止验证期间声称修复已通过。
