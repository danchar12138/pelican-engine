# M1：正式编译与运行时契约

状态：实装完成，集成验收中。对应版本 `0.1.0-m1.0`。产品范围不变，M1 不替代 M2–M8。

## 模块所有权

- `packages/sdk` 定义公开类型、组件、阶段、系统上下文及可序列化内容入口。
- `packages/compiler` 拥有静态声明提取、类型检查、系统/版本契约检查、IR 和内容哈希缓存。`experiments/compiler` 只保留历史导入兼容。
- `packages/runtime` 拥有 SoA World、代际句柄、事务结构命令、调度、时钟、随机、事件、录放和资源生命周期。
- `packages/renderer` 读取 RuntimeHost 派生状态，内部使用 Three.js WebGPU/TSL；不作为游戏状态的权威来源。`experiments/render` 保留历史入口。
- `packages/protocol` 是命令与结果 envelope 的权威类型与校验来源；CLI 和控制桥共用。
- `packages/schema` 从 SDK 组件声明派生 JSON Schema，API 索引也从 SDK 源码生成，不手写重复签名。

## 数据与执行

number/boolean/vec3 使用真实类型化列存储，字符串使用独立列；查询按实体索引稳定排列。运行态句柄包含 world/index/generation；恢复会失效旧句柄，持久引用使用稳定内容 ID 重新解析。

结构命令在候选列状态完成校验后统一交换；失败批次不部分提交。此实现尚未使用增量事务日志，结构变更成本会单独测量，不夸大高实体吞吐。

系统按六个阶段和 before/after 依赖执行，读写权限由 World 检查。未声明权限保留 M0 源码兼容，显式空列表严格限制。冲突被排序与报告，不宣称自动多线程。

输入通过下一 tick 的事件进入固定模拟步。随机源、事件队列、世界和时钟进入完整快照；录放不包含任意闭包变量、外部 IO 或 GPU 状态。失败 tick 保留可能的部分状态并暂停，不计为成功，恢复有效快照后再执行。

## 资源与加载

资源句柄、共享单次加载、独立引用、作用域、取消和过期结果清理均由资源管理器负责。描述符快照用于重建身份，不保存 GPU 对象。浏览器内容加载先准备候选 Host，再切换；加载失败保留现有运行状态。

原生 JS module cache 无法卸载；管理器报告的是引用和所有权，不是操作系统或驱动层内存审计。预算未知明确为 unknown。

## 外部开发操作

命令行可查询已运行状态、单步、投递输入、保存恢复、录放和捕获当前画面。开发控制桥只附着 localhost dev 服务；发布产物不包含浏览器控制入口或 HTTP 控制路由。

命令串行、有界超时和可取消。运行中取消会丢弃会话并明确要求重置，不假装保留任意中间状态。没有专用 AI 客户端、云平台或运行时模型。

## 版本与边界

项目 manifest 版本必须与引擎匹配；编译器检查本地引擎路径身份。M0 锁定项目需显式迁移，不自动改用户游戏。保留无 manifest 的历史源码兼容警告，正式新项目始终生成锁定信息。

增量缓存仍为整项目哈希复用，开发变更采用明确冷重载；任意状态热替换不是 M1 完成声明。完整高质量材质、纹理、角色/物理/动画、UI/音频及动态世界仍按后续阶段实现。
